# Class Dashboard 2.0｜教室日常

I-D 驗收修正版本 `2.0-ID.0`：臺灣國民小學日常教室資訊與班級管理儀表板。原生 HTML / CSS / JavaScript ES Modules，無後端、資料庫、登入帳號、付費 API；YouTube 選用官方 IFrame API。

沿用既有三欄、六風格／十八配色及時鐘、課表、倒數、抽號與影音核心，I-C提示音與聚焦已完成；本次I-D進行回歸驗收及兩項小修正，不增加新功能、任務或水族箱。

## I-C：提示音與通用卡片聚焦

以最新 main 820ed7a（已合併 PR #11）增量開發，保留既有三欄、18 配色、四專注及影片放大。

- 倒數卡「提示音設定」與「教師設定 → 教室工具」共用同一份設定，自動保存。提供明確開關、電子提示音／柔和鐘聲／清脆鈴聲、0～100%音量、1／2／3次及試聽。關閉提示音仍可試聽，0%顯示靜音。
- 提示音使用一個共用 Web Audio 引擎，原創合成無素材授權依賴；新試聽先取消前次提示音，音量不改背景影音。試聽不啟動／改變倒數；到時先保存結果再提示，音訊失敗仍顯示時間到。
- 左側課程事項、中央展示、右側工具各有放大入口。原有 DOM 直接進入原生模態上層，背景淡化且不可誤操作，Tab／Shift+Tab留在視窗，Esc／關閉返回原入口。不複製資料或媒體；中央影片仍使用原影片放大。
- 「放大」是暫時視窗；「專注展示」是原有保存的顯示模式。切入舊專注會先關閉通用聚焦，管理／影音視窗亦共用單一模態協調。
- 資料升級 schema 7→8，僅新增 `preferences.timerSoundType`、`preferences.timerSoundCount`。保留舊開關、音量，預設電子音3次，原學生ID、課表、事項、影音與歷史不變。JSON formatVersion仍為1。

升級前先備份、關閉其他舊分頁。舊schema7程式無法讀取schema8，回退時須使用升級前備份與相容程式，不要手動改版本號。遷移載入不立即改寫，首次成功操作才保存schema8；Web Locks及過期分頁保護沿用。

## 三欄首頁與多媒體整合

標準桌面以左 20%／中 60%／右 20% 為目標：左側今日／整週／班級事項，中央時間與課程／倒數／抽號／教學影片，右側音樂／影片清單／其他工具。時鐘與課程使用同一張卡片，寬螢幕左右並排、窄螢幕上下排列。

- 班級事項沿用唯一聯絡簿資料、完成狀態、完整檢視與編輯，不增加第二張卡片或重複入口。
- 右側音樂有播放／暫停、上一首／下一首、音量／靜音，完整清單可管理原有網址及本機媒體。切中央頁籤不停止背景音樂。
- 右側影片清單可搜尋、分類及「中央播放」；本機檔案從完整多媒體加入，僅本次頁面有效。右側不放大型影片。
- 影片與 YouTube 容器從初始化起固定在中央，只有一個 audio／video／YouTube adapter。原生影片使用瀏覽器控制進度、音量、播放；YouTube 使用官方控制。
- 切離中央影片頁籤會暫停同一來源並保留原生播放進度；YouTube API 就緒時送出暫停並保留 iframe。API 未就緒且無法確認暫停時沿用安全停止，明示原因，不保證此情況的進度。
- 「放大置中」開原生模態展示，Esc／還原回中央；「全螢幕播放」使用 Fullscreen API 的影片容器。過程不重新掛載媒體節點。停止影片會清理來源，且不自動恢復音樂。改播其他來源仍沿用原引擎停止舊來源規則。
- 倒數仍是原時間戳核心，切頁保留提示；抽號不重置。計時器原有音樂／影片連動有效。四專注、原全螢幕、投影隱私、六風格18配色仍可用；三布局偏好小幅調整三欄比例。
- 目前schemaVersion 8、JSON格式1；遷移只增提示音欄位，沒有改學生ID、課表、事項或影音資料模型，不清空 localStorage；Web Locks 與過期頁保護保留。

[截圖、差異、測試、修改檔案與限制](docs/three-columns-report.md) · [Windows11 操作指南](docs/windows11-guide.md)。三欄版原由PR #10延伸；目前PR #11已合併main，本次I-C以其成果為基準。

## 多媒體中心（Windows 11）

1. 在 Chrome／Edge 點底部工具列「多媒體中心」。大型播放器只存在網頁內對話框，背景的課表與倒數持續運作。
2. 「音樂」可一次選多個本機 MP3／WAV 等檔案，再點暫存佇列的播放；也可輸入名稱與 HTTPS 直接音訊網址，按「加入音樂並播放」。選檔本身不自動播放。
3. 提供播放、暫停、停止、上一首、下一首、音量、靜音、進度、時間、倍速、單曲／全部／不循環及隨機。不循環會播完本輪後停止；隨機模式避免本輪重複，手動下一首可重新開始選曲。
4. 「影片」可選本機 MP4／WebM，或輸入 HTTPS 直接影片／常見 YouTube 網址。依實際編碼決定能否解碼；副檔名不保證可播放。新影片會捲到播放器，比例使用 contain 保留。
5. 本機／直接影片可用原生控制、共用控制及影片全螢幕。YouTube 使用 youtube-nocookie.com 的官方嵌入與內建控制；本站播放／暫停／進度／音量／倍速按鈕對 YouTube 停用，停止仍可移除 iframe。它的播放狀態顯示為「官方播放器已開啟」，不假裝已知正在播放。
6. 關閉音樂視窗可繼續背景播放，首頁工具列下方顯示迷你控制列，可暫停／繼續／停止及重新開啟。停止即收合，不遮住教室工具。
7. 關閉影片視窗（含 Esc）、切到音樂或改播其他來源，會先停止影片並移除 src／iframe，不留下隱藏音源。同一時間只有一個主要播放器。若開啟合法原始來源，會先停止本站的來源；新分頁之後由瀏覽器與該網站管理。
8. 「清空暫存佇列」需確認；只移除本頁暫存，不刪電腦原始檔。佇列中的本機 Blob URL 保留供本次重播，停止時先卸載解碼來源，清空／離開頁面再回收不再需要的 Blob。

### 4C 預存清單與智慧連動

1. 多媒體中心 →「新增／編輯影音網址」→ 填名稱、音樂／影片、HTTPS 網址及分類 →「儲存影音網址」。選擇音樂時需直接音訊來源；YouTube 請選影片。儲存只保存網址，不下載檔案，也不立即播放。
2. 用「清單」選全部、音樂、影片或最愛，搭配分類／搜尋；點「播放」沿用共用播放器。可以編輯、加入最愛、刪除及上／下移。篩選時的移動是相對於目前可見的相鄰項目；保存順序以單一陣列為準，播放不因搜尋而改變。
3. 「管理分類」可新增、改名或確認後刪除；刪分類不刪影音，會移至保留的「其他」分類。分類上限 50，網址上限 500。名稱與匯入文字只作文字呈現，不作 HTML。
4. 網址、名稱、類型、分類、最愛及順序會保存；音量／靜音／倍速／循環／隨機偏好也保存。本機檔案及下方的暫存網址仍只在本次頁面有效，重新整理需重新選檔；不儲存 Blob URL 或影音檔案。
5. 「計時器與影音連動」預設不自動播放。可選已儲存音樂，設定開始／繼續播放、暫停計時是否暫停音樂、計時結束繼續／暫停／停止音樂，以及結束時暫停影片。保存設定不立即播放；新一次「開始／繼續」才觸發。重整／還原不自動播放。已在播放同一首音樂時不從頭重播，暫停後繼續也保留位置。
6. 結束／暫停規則適用當時的影音，不限連動選曲。YouTube 結束時暫停使用官方 IFrame API；API 未就緒時會卸載影片，避免留下聲音。本站不宣稱掌握其實際播放狀態。網路／平台阻擋時顯示原因，計時照常；提示音和影音音量獨立。
7. 編輯正在播放的名稱不重播；更換其來源、類型或刪除，成功保存後才停止舊來源。刪除連動選曲或把它改成影片，會取消音樂連動選擇。儲存失敗保留原清單與既有播放；偏好失敗則恢復上次保存值。
8. 教師設定 → 資料管理 → 完整 JSON 備份包含網址庫、分類、最愛、順序、偏好與連動設定，同時保留學生、課表和舊任務歷史。還原仍需驗證、預覽及確認；不是遠端同步。


## 4A 展示與操作

- 原生 Fullscreen API：進入／退出、Esc、狀態及拒絕提示，不重載、不重設工具。全螢幕狀態不寫入資料，也不假定重整後仍全螢幕。
- 四種專注模式：大型時鐘、大型倒數（含剩餘進度條）、今日課表、大型抽號。重用原本工具元素與狀態，返回主畫面按鈕清楚保留。
- 三種布局：標準、時鐘優先、課表優先；四種字體：小／中／大／特大；三種主題：深海預設、明亮、高對比。皆經集中狀態入口保存與完整備份還原。
- 投影隱私：開啟時關閉教師設定，阻擋學生名單、匯入、還原與所有設定入口，須明確關閉才能開啟。重整仍保留。其他分頁啟用隱私時，本頁會先關閉敏感設定並要求重新整理。
- 快速工具列、輸入安全快捷鍵、觸控目標、持續錯誤通知、reduced-motion。多媒體中心已由 4B 接入同一工具列，首頁不固定顯示大型播放器。

投影隱私只是畫面保護，不是登入、權限驗證或資料加密；學生資料仍在瀏覽器資料與完整備份中。不要把它當作阻止他人讀取電腦資料的機制。

### 4A 快速操作（Windows 11）

1. 快速工具列選「大型時鐘／大型倒數／今日課表／大型抽號」。每種模式都使用原有課表、倒數與抽號紀錄。按「返回主畫面」恢復。
2. 「進入全螢幕」使用瀏覽器 API；按按鈕或 Esc 退出。可先進入專注再全螢幕，也可在全螢幕切換專注。退出全螢幕不退出專注，也不停止計時。
3. 切換字體、主題及布局會自動保存。字體會依容器與畫面高度限制，避免過大數字擋住按鈕；某些短螢幕的字級會達相同安全上限。手機及特大字模式可正常垂直捲動。
4. 投影時開啟「投影隱私」。要操作名單、匯入或還原，先明確按「關閉投影隱私」，再開啟教師設定；關閉設定後可再啟用隱私。
5. 快捷鍵：1 時鐘、2 倒數、3 今日課表、4 抽號、0 返回主畫面、F 全螢幕、S 教師設定。倒數專注模式的空白鍵為開始／暫停／繼續。非輸入狀態按 Esc 可返回主畫面；全螢幕內 Esc 先退出全螢幕。按鍵在文字、輸入法組字、按鈕／選單／原生控制項、對話框及 Ctrl/Alt/Meta/Shift 組合時不攔截。
6. 全螢幕被拒絕時，查看工具列提示，改用 Chrome／Edge 直接開啟網站。沒有用 CSS 冒充全螢幕。儲存失敗時偏好不會套用成成功狀態，也不會清除資料。

第三階段教師設定仍有四個真正分頁：

1. **班級與學生**：改班名、逐筆新增及編輯、學生名單範本與匯入。座號 1–50 不重複，姓名選填、最多 40 字。匯入預覽中，重疊座號需逐列選擇明確的既有身分；不按姓名推測。不在匯入表內的學生及歷史不刪除。
2. **作息與課表**：選擇或建立民國學年／學期、編輯作息、單一課程、課表範本／匯入、單日調課。作息表下按「儲存整份作息」才提交整份編輯；重疊或刪除仍被課表引用的時段會被拒絕。新學期可沿用固定課表，但不沿用單日調課，也不重設學生。
3. **教室工具**：設定倒數分鐘／秒數及提示音、編輯聯絡事項、今日抽號參與及重設抽號輪次。首頁可直接操作開始／暫停等計時按鈕與抽號。
4. **資料管理**：顯示儲存狀態與版本、下載完整備份、選取 JSON → 檢查預覽 → 勾選覆蓋確認 → 正式還原。備份含學生個人資料，請妥善保存；下載不是遠端同步，請確認檔案確實儲存到指定位置。

課表在首頁可切換今日／整週。整週表顯示固定課表；臨時調課在今日及目前／下一節顯示「臨時」。週末顯示休息日。選定的學期會持續使用，學期切換由教師明確操作，不按日期偷偷替換。

重新整理不會清空資料。請勿清除瀏覽器網站資料。換瀏覽器、電腦、網址來源或連接埠時是不同資料，需要透過完整 JSON 備份移轉。抽號狀態直到手動重設才開始新一輪，不會因日期改變偷偷重抽。

## 課表標準範本

| 星期 | 節次 | 科目 |
| --- | --- | --- |
| 星期一 | 第一節 | 國語 |
| 星期一 | 第二節 | 數學 |
| 星期二 | 第一節 | 自然 |

可交換三個欄位的順序；星期接受「星期一」至「星期五」或 1–5。節次名稱必須對應目前作息中的授課時段。科目 1–40 字。匯入只更新預覽列出的課程，其他既有課程保留。重複星期＋節次、無效星期、未知節次與空科目會拒絕。手動編輯科目留空可清除。

CSV 使用 UTF-8；範本含 BOM，適合 Windows Excel。XLSX 支援第一張工作表、一般數字及 inline/sharedStrings；不做任意排課版型辨識。拒絕公式、合併儲存格、巨集、加密、外部連結、ZIP64 與超限內容。檔案上限 2 MB、最多 128 個 ZIP 項目、單項解壓 2 MB、總解壓 8 MB，校驗 CRC。採原生 DOMParser / DecompressionStream，不使用第三方 XLSX 解析套件。不支援原生 deflate-raw 的瀏覽器請更新或改用 CSV。檔案只在本機處理，不上傳第三方。

## 資料版本及保護

資料鍵仍為 `class-dashboard-v2`，目前 `schemaVersion: 8`。版本 1→2→3→4 的既有遷移鏈保留，4→5 新增 display 展示偏好，5→6 只新增 mediaLibrary 網址庫、分類、偏好與預設停用的計時連動；6→7新增appearance外觀配對（預設legacy/default），7→8新增提示音種類與次數（預設電子音3次），保留原 display 與 students、templates、rounds、participation、rosterImports 與其他既有欄位。舊網站的 `aquarium-classroom-v1` 鍵不讀寫。

讀取及記憶體升版不會寫回。重要變更依序為命令 → 計算下一狀態 → 全部驗證 → localStorage 寫入成功 → 更新畫面。失敗不宣告成功。Web Locks 使用同一個 `class-dashboard-v2-write` 名稱；還會比對原始資料快照，拒絕過期分頁、同 revision 外部改寫及過期匯入預覽。舊版無法解析新版 schema，不能交互覆蓋；升級前後仍建議關閉其他舊分頁並保留備份。

資料損壞不會初始化覆蓋：一般寫入鎖定，資料管理可先下載「原始資料保護副本」，再預覽並明確確認還原有效完整備份。讀取本身被瀏覽器禁止時，需修復瀏覽器設定並重新整理。不要以清除 localStorage 當作修復。

JSON 格式為 `{app:'class-dashboard-v2',formatVersion:1,exportedAt,data}`，上限 8 MB，拒絕未來資料版本、錯誤格式及不一致模型。還原也經寫入鎖、過期預覽檢查及原子保存，revision 會使用目前 revision+1，不回到備份舊編號。不存在自動還原或背景清理任務。還原備份會依教師確認取代全部資料，建議先下載目前備份。


用瀏覽器開啟 `http://localhost:8000/class-dashboard-v2/`，保持命令視窗開啟，結束時 Ctrl+C。若從此子目錄啟動伺服器，網址改用根路徑。不要直接雙擊 HTML，ES Modules 不適合 file://。

```bat
npm test
```

瀏覽器測試需要先啟動伺服器，以及測試用 Playwright（不是網站執行期依賴）：

```bat
npm install --no-save --package-lock=false playwright
set CHROMIUM_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
npm run test:browser
```

Edge 可改為 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，依實際位置調整。Linux 預設 `/usr/bin/chromium`，可用 `TEST_URL` 指定測試網址。舊任務 UI／命令測試保留為 `tests/legacy/` 的歷史文字，不算本版通過測試；本版以真實 schema 3、4 fixture 驗證歷史保留、升版與拒絕任務操作。

## 已知限制及後續邊界

本批次已進行I-D可支援的整合驗收及必要修正，完成後停止等待確認，不開始第五階段。Windows 實機、第三方影音與正式 Pages 的環境驗收仍待執行，不能等同所有部署與設備皆已通過。選配的獨立瀏覽器視窗延後，不影響網頁內多媒體中心使用。完整 CSV 報表、學期封存及進階診斷留待第五階段。水族箱相關後續開發已取消；任務僅保留歷史相容性。
