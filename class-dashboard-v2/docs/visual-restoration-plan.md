## 共同規範

- 所有文字與操作為真實 DOM；時鐘、課表、倒數、抽號、媒體共用原 store／核心，沒有整圖介面或虛構數值。
- 三個原有布局、四級字體、高對比及 reduced-motion 保留。主題構圖用 Grid areas 實際調整，字體與圖示按容器／可用高度響應。
- 頁首保留外觀、展示控制、全螢幕、教師設定；原顯示選項移入單一原生 dialog，原 ID／資料／事件沿用。首頁另設真實媒體／事項／名單／展示捷徑，不能為填滿空白增加未知功能。
- 上方時間與課程分卡，保留既有 ID；新增只讀事項摘要，仍引用 notes，不另存或新增第二套編輯器。原三頁籤與完整內容入口保留。
- 一般桌機單屏；長內容走摘要／完整視窗，極端文字／小螢幕保持既有閱讀降級，不以 overflow:hidden 裁切。
- 高對比移除背景插畫及透光裝飾，提供實底與可見焦點。新素材不依賴網路 API 或外部字型。

## 必要素材與權利

計畫為每風格繪製獨立原創 SVG 場景及卡片插畫：A 校園與揮手人物；B 教室書架與閱讀人物；C 校園山丘與書本文具；D 幾何地形與數學工具；E 低彩度波紋及線圖；F 拱窗／花枝／燈籠與書本。另以共用原創 SVG symbol 建立時鐘、課程、課表、筆記、抽號、媒體、展示、名單圖示，透過風格樣式改變呈現。

不擷取參考圖人物、不將參考圖當作背景或描摹成不可操作介面；素材本身只含裝飾，沒有數字、科目、文字或按鈕。SVG 文字檔可離線、壓縮傳輸、放大不失真，另附授權說明。

## 參考與現有功能的差異

參考中的正計時、分組、抽任務、老師姓名、課程單元、學習統計、加分／獎勵、噪音、白板、圖片／網頁瀏覽、畫面凍結／黑屏等並非現有功能；不新增、不做假按鈕。筆記對應電子聯絡簿，抽籤對應抽號，工具只接現有入口。main 沒有 I-C 的全新卡片聚焦／三音效試聽，保留既有專注及完整內容視窗，明列相依而非冒稱存在。

## 驗證方式

每風格三配色於 1920×1080、1366×768、1024×768 各截圖，至少 54 張；測頁籤、真實控制、顯示 dialog、媒體生命週期／計時與資料相容，執行可用回歸。人工逐款對照本對話參考圖，報告列方法／預期／實際／狀態／嚴重程度／建議。

參考原 PNG 僅在本對話可見，Windows 路徑不是工作區可讀路徑，附件掛載中沒有這六個 PNG。因此可目視比較，但不能偽造已完成原圖檔案像素比對或附入原 PNG；報告以參考構圖摘要與實際截圖並列，清楚記錄此限制。實機 Windows／白板／喇叭及第三方影音須列未驗證。
