# Windows11｜I-C提示音與聚焦（2.0-IC.0）

1. 升級前先下載完整JSON備份並關閉其他舊分頁；更新後資料版本8。不要清除瀏覽器資料或手動改版本號。回退舊程式需升級前備份。
2. 中央選「課堂倒數」，點「提示音設定」。教師設定的教室工具也有同一組設定。明確開關顯示開啟／關閉，改音效、音量或次數後自動保存；拖音量時顯示百分比，放開後保存，0%為靜音。
3. 三種聲音為原創電子音、柔和鐘聲、清脆鈴聲。選1／2／3次，點「試聽提示音」。即使正式提示音關閉仍可試聽；試聽不啟動倒數、不改剩餘時間、不改開關。
4. 若顯示未儲存，設定會回復原值，請保留錯誤並檢查瀏覽器儲存空間。若試聽失敗，檢查網站音效權限、喇叭／音量與瀏覽器；到時文字仍顯示。
5. 左側「放大」可閱讀今日／整週／班級事項；中央「放大展示」可看大型時鐘、倒數或抽號；右側「放大工具」可操作音樂與清單。可在放大後切換同區頁籤。
6. 背景淡化後不可誤點，按右上關閉或Esc返回原入口。Tab／Shift+Tab在視窗內循環。計時、抽號及影音不因放大重建。
7. 原有「專注展示」仍是獨立模式；切入專注或打開教師設定時，會關閉通用聚焦。要組合全螢幕，可先由頂部進入全螢幕再放大。影片仍用原有影片放大及全螢幕，不建立第二套影片視窗。
8. 驗收三解析度1920×1080、1366×768、1024×768及18配色。放大視窗內長內容可捲動；小視窗／高縮放依既有可讀布局處理。
9. 計時1～3秒，開／關提示音各試一次，確認時間到文字、次數及音量；播放背景音樂時試聽，確認媒體音量不變。JSON下載、預覽、確認還原後檢查提示音偏好及學生／課表／事項。
10. 開發環境已跑API及模擬測試，實際Windows11 Chrome／Edge、白板、喇叭音色及第三方影音仍需你在實機確認。

# Windows11｜三欄首頁（2.0-three-columns.0）

1. 更新前先下載完整 JSON 備份，關閉其他舊分頁；不要清除網站資料。
2. 左側切今日、整週、班級事項；完整檢視可放大閱讀，班級事項的編輯仍在教師工具。它是唯一聯絡簿入口。
3. 中央切時間與課程、倒數、抽號、教學影片。時間與課程共用一張卡片；倒數在其他中央頁籤仍有可點擊的進行／暫停／時間到提示，抽號結果不因切頁改變。
4. 右側「音樂」可播放／暫停、上一首／下一首、音量／靜音；「完整播放清單／選檔」沿用原管理視窗。音樂切頁仍播放，影片接管時停止舊音源，不自動恢復。
5. 右側「影片清單」搜尋、選分類、按「中央播放」。本機影片按完整清單／本機影片選檔，再按暫存佇列播放，會回到中央。檔案不會上傳、寫入 localStorage 或 JSON，刷新後須重新選檔。
6. 原生影片用畫面內控制操作進度／音量；YouTube 使用官方控制。切離中央影片時暫停，回到影片按播放或官方播放鈕繼續。改播音樂或另一來源、停止影片，會沿用原引擎清理舊來源，不能把它當成同一影片的暫停。
7. 「放大置中」開原生模態展示，按 Esc／還原回中央；全螢幕播放由瀏覽器 Fullscreen API 執行。這些操作不搬動播放器節點。
8. YouTube API／網路未就緒時，若不能可靠暫停會停止來源並提示，這種情況不保證保留進度。禁止嵌入、地區、年齡或平台限制不會繞過，請使用合法原始頁面。
9. 右側其他工具集中現有完整多媒體、專注展示、班級學生、課堂工具；頂部保留外觀、展示控制、全螢幕及教師設定。投影隱私啟用時，學生及敏感設定停用。
10. 逐一試1920×1080、1366×768、1024×768可用視窗及18配色。寬不足960或高不足620可捲動閱讀；列表及子畫面可內部捲動。實際 Windows Chrome／Edge、白板、喇叭與合法 YouTube 仍需實機驗收。

# Windows11｜新首頁快速操作（2.0-home-layout.0）

1. 更新前先由「教師設定 → 資料管理」下載完整 JSON 備份；不要清除網站資料。
2. 左側切換「今日課表／整週課表／班級事項」。班級事項即電子聯絡簿，按下方「查看完整事項」閱讀、按「編輯事項」修改；完成狀態保留。
3. 中央切換「教室時鐘／課堂倒數／隨機抽號」。時鐘與目前課程在同一展示區。倒數開始後可切到其他頁籤，右上方提示顯示剩餘時間；點提示可返回倒數。暫停、繼續、重設使用原狀態。
4. 倒數的「常用時間／增減」提供預設時間及加減分鐘；「時間與提示音」開啟既有教室工具設定，保留原提示音及音量，不是新音效試聽功能。
5. 抽號不因切頁重置，依今日參與排除、同輪不重複。可看抽號紀錄及參與設定。
6. 底部：多媒體中心、專注展示、班級與學生、課堂工具。專注展示開啟目前中央內容的原有專注模式；返回主畫面恢復剛才中央頁籤。課表專注可在頂部「展示控制」選擇。
7. 頂部「外觀主題」選六風格三配色，預覽、確認才保存；「展示控制」選字級、可讀性、左右布局偏好、隱私及專注。全螢幕為獨立瀏覽器狀態，可與專注組合。
8. 投影隱私啟用時，學生管理及敏感設定停用；須先明確退出隱私。這不是帳號權限。
9. 在實際 Chrome／Edge 以 1920×1080、1366×768、1024×768 可用視窗驗收三個中央模式；再試大字、高對比、全螢幕、觸控。極小視窗或高縮放可捲動閱讀。
10. 播放本機音樂、切頁確認不中斷；關閉影片確認停止。另行測試實際喇叭、白板及可合法嵌入的 YouTube。Linux Chromium 測試不能代替 Windows 實機或第三方平台實播。

## 更新前後

1. 教師設定 → 資料管理 →「下載完整 JSON 備份」，確認檔案確實存在下載資料夾；另存到自己的安全位置。備份含學生個人資料，請妥善保存。
2. 關閉此網站其他舊分頁。版本更新後可按 Ctrl＋F5，頁尾及資料管理應顯示 `2.0-integration-IB.0`／資料版本 7。
3. 確認原有學生、課表、調課、聯絡簿及抽號狀態仍在。請勿清除網站資料或 localStorage；也不要讓不同版本同時編輯。
4. 更換電腦、瀏覽器或網址來源需要透過 JSON 移轉。自動保存只存在目前瀏覽器，不等於外部備份或遠端同步。

## 教室展示

- 快速工具列可切換大型時鐘、倒數、今日課表及抽號；「返回主畫面」恢復。全螢幕按鈕使用瀏覽器 Fullscreen API，Esc 退出。退出全螢幕與退出專注是分開的，不會重設計時或抽號。
- 主題有深海、明亮、高對比；字體小／中／大／特大；布局標準／時鐘優先／課表優先。設定自動保存，小螢幕可以垂直捲動。
- 投影前開啟投影隱私；要編輯名單、匯入或還原，必須先明確關閉隱私。這是畫面保護，沒有帳號認證，亦不遮蔽教師主動展示的影音名稱或網址。
- 非輸入狀態快捷鍵：1 時鐘、2 倒數、3 今日課表、4 抽號、0 主畫面、F 全螢幕、S 設定。倒數專注時空白鍵可開始／暫停／繼續。文字、輸入法組字、按鈕／表單、對話框及瀏覽器組合鍵不攔截。

## 班級與教室工具

教師設定四頁保留：班級與學生、作息與課表、教室工具、資料管理。名單及課表均可下載 CSV／XLSX 範本，選檔 → 預覽 → 檢查 → 確認；失敗不覆蓋原資料。名單重疊座號需明確指定既有學生，不按姓名猜測身分。

作息為課表共同時間來源；固定週課表長期沿用，單日調課只改指定日期，整週表仍顯示固定課表。週末不套用週一。倒數使用結束時間戳記，刷新及切分頁仍正確。聯絡簿可編輯、排序、完成及確認後清除完成事項；抽號依今日參與、本輪不重複並保存紀錄。

## 多媒體中心

1. 點「多媒體中心」開啟網頁內子畫面。音樂／影片分頁可選本機檔案或加入本次暫存網址。選檔不立即播放；點佇列的播放。重新整理後需重新選本機檔案，電腦原檔不會被修改。
2. 要長期使用網址，開啟「新增／編輯影音網址」，填名稱、音樂／影片、HTTPS 網址及分類，按儲存。音樂需直接音訊來源；影片可為直接影片或支援的 YouTube 網址。儲存不下載檔案，也不立即播放。
3. 用搜尋、音樂／影片／最愛、分類找到項目，點「播放」。可以編輯、加入／移除最愛、上移／下移或確認刪除。分類可自訂、改名；刪分類後項目移至「其他」並保留。網址最多 500 筆，分類最多 50 個。
4. 本機／直接影音可控制播放、暫停、停止、位置、音量、靜音及倍速；音樂另有上一首、下一首、循環及隨機。偏好會保存。YouTube 主要使用官方播放器內建控制；本站不控制其廣告，也不宣稱知道實際播放狀態。
5. 關閉音樂視窗後可繼續播放，主畫面迷你列可暫停、繼續、停止及重開中心。關閉影片或按 Esc 必須停止影片；改播另一來源時先停止／暫停舊來源。若開啟原始來源，本站先停止自己的音源，新分頁之後由該網站管理。
6. API 網路暫時失敗後，可檢查網路並重新點選 YouTube 影片。禁止嵌入、來源刪除、年齡或地區限制不能由本站繞過；可查看官方提示或開啟合法原始來源。錯誤不刪清單，不應影響課表或倒數。
7. 正在播放時改名稱不重播；改來源／類型或刪除，成功保存後停止舊來源。刪除連動選曲或改為影片會取消音樂連動選擇。保存失敗時，原清單和播放保留；偏好恢復上次保存值。

## 倒數與影音連動

多媒體中心 →「計時器與影音連動」。預設不自動播放。可指定保存的音樂，選擇開始／繼續時播放、暫停計時是否暫停音樂、結束繼續／暫停／停止音樂，也可設定結束時暫停影片。

保存設定不立即播放，下一次按「開始／繼續」才觸發；重整及還原不會自動播放。音樂已在播放不重啟，同首暫停後繼續保留位置。結束／暫停規則適用當時的影音。YouTube 使用官方 API 暫停，若未就緒則移除播放器以避免留下聲音。播放遭瀏覽器阻擋仍照常倒數，可看主畫面迷你列的中文原因並手動播放。

計時提示音與媒體音量分開管理。請在教室電腦實測 Windows 音量、瀏覽器音量、喇叭輸出及靜音設定；到時一定有文字提示。

## JSON 還原與錯誤處理

資料管理 → 選取 JSON → 預覽班級、學生、學期、歷史、影音與分類數量 → 勾選覆蓋確認 →「確認還原完整備份」。新版完整備份含清單、分類、最愛、順序、播放偏好與連動；不含實際影音檔案。

- 儲存失敗：不要以清空資料解決，先下載仍可讀取的備份，檢查儲存空間及瀏覽器隱私設定。
- 過期分頁：關閉其他舊分頁，保存所需備份後重新整理再操作；錯誤提示不代表剛才操作已保存。
- 原資料異常：先下載「原始資料保護副本」，再使用已驗證備份還原。不相容或無效 JSON 會拒絕，失敗不覆寫原資料。
- 新版未出現：依部署說明確認 PR 是否已合併與 Pages 部署成功，再 Ctrl＋F5；不要刪資料或自行改路徑。
